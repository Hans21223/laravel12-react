# Anaheim workspace UX refresh

The dashboard now starts with review actions and shortcuts for leave, budget, and document requests. Recent requests appear before charts. Shortcuts select the corresponding request type in the existing form.

Navigation separates daily work (overview, personal requests, approvals, and all requests) from the employee directory and messages. Settings remains visible; reports, organization administration, database inspection, diagnostics, and help live in an expandable Workspace tools group. Opening one of those views also expands its group.

On phones, request rows become cards with readable titles, owners, status, priority, and due dates. The same table data and request buttons are retained. Form actions remain available in a sticky dialog footer. A keyboard skip link moves focus to the main content.

Visual changes include larger headings and controls, restrained navy/red colors, rounded panels, consistent shadows, circular avatars, status pills with dedicated dark-mode colors, and native checkboxes styled as settings switches. Existing reduced-motion preferences are respected.

Validation: production build; 495 matching translation keys across English, Thai, and Japanese; browser screenshots of overview, lists, settings, dialogs, mobile navigation, and dark mode; interactions for quick creation, secondary navigation, settings switches, and mobile cards at widths 360, 390, 768, 1024, 1440, and 1918 pixels. No horizontal page overflow or JavaScript errors in those interaction checks.

These are design and interaction improvements, not results from a user research study. Approval permissions, database boundaries, API behavior, messaging, and calls are unchanged.
